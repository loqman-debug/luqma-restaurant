# لقمة | LUQMA • Gourmet Cinematic Experience 🍔🍕🍗

تجربة رقمية سينمائية استثنائية لمطعم **«لقمة»** مبنية بتقنية الحكاية التفاعلية مع السكرول (**Scroll-Driven Storytelling / Scrollytelling**)، تأخذ العميل في رحلة طهي بصرية حية تجمع وجبات البرجر، البيتزا الإيطالية، والبروستد الذهبي طبقة بطبقة في الهواء ثم تُغلفها وتنطلق بها مباشرة لباب العميل.

---

## ✨ المميزات الرئيسية (Key Highlights)

- 🎬 **حركة مرتبطة بالسكرول بنسبة 100% (1:1 Scroll-Bound Motion):**
  الحركات ليست مجرد رسوم متحركة تعمل بمؤقت زمني مستقل، بل هي محكومة بدقة موضع التمرير للمستخدم (للأمام، للخلف، والتوقف المؤقت).
- 📸 **أصول تصويرية واقعية عالية الدقة (Photorealistic Studio Assets):**
  تفكيك وجبة البرجر إلى 5 طبقات فيزيائية شفافة مفرغة الحواف بجودة إعلانية، بالإضافة لأطباق البيتزا والبروستد على ألواح خشبية فاخرة.
- 📦 **تغليف واقعي ومختوم (Physical Packaging & Security Seal):**
  محاكاة حقيقية لنزول الطعام داخل تجويف علبة الكرافت، وإغلاقها بختم الأمان الذهبي العربي قبل انطلاقها للتوصيل.
- 🔊 **محرك مؤثرات صوتية إجرائي (Web Audio API Foley Engine):**
  أصوات تفاعلية خفيفة ومحاكية لطقطقة وتجميع الطبقات دون الحاجة لملفات صوتية ثقيلة.
- 🛒 **سلة طلبات تفاعلية وربط مباشر مع واتساب (Interactive Cart & WhatsApp Checkout):**
  درج جانبي سلس لإدارة الطلبات، حساب المجموع الفرعي وضريبة القيمة المضافة (15%)، وتجهيز رسالة نصية فورية للطلب عبر واتساب.
- 🎨 **هوية بصرية دافئة وشهية (Warm Gourmet Aesthetic):**
  لوحة ألوان مستوحاة من الأطباق المحمصة والخبز الذهبي (`#fff9f2`, `#f48c06`, `#2a160b`) مع دعم كامل للتبديل بين الوضع الدافئ والوضع الليلي الفاخر.

## 🚀 التشغيل محلياً (Local Setup)

لا توجد أي حزم برمجية معقدة مطلوبة (Zero Dependencies). يمكنك تشغيل الموقع محلياً عبر أي خادم ويب ثابت:

### باستخدام Python:
```bash
python -m http.server 3000
```
ثم افتح المتصفح على: `http://localhost:3000/index.html`

### باستخدام Node.js / npx:
```bash
npx serve .
```

## 🌐 النشر عبر GitHub Pages (Live Deployment)

لرفع المشروع على GitHub وتفعيله مباشرة:

1. **ارفع الكود إلى مستودعك:**
   ```bash
   git add .
   git commit -m "feat: Initial release of Luqma restaurant experience"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```

2. **تفعيل الرابط المباشر:**
   - توجه إلى إعدادات المستودع **Settings** في GitHub.
   - اختر **Pages** من القائمة الجانبية.
   - في قسم **Build and deployment**، اختر الفرع **`main`** ثم اضغط **Save**.
   - سيتوفر موقعك خلال دقيقة على الرابط: `https://USERNAME.github.io/REPO_NAME/`

## 🛠 التقنيات المستخدمة (Tech Stack)

- **HTML5 & Vanilla Modern CSS3** (CSS Grid, Flexbox, 3D Transforms, Backdrop Filter).
- **Vanilla JavaScript (ES6+)** مع حسابات دقيقة لفيزياء السكرول والتسارع التكعيبي.
- **Web Audio API** للمؤثرات التفاعلية الإجرائية.
- **Python Pillow & Arabic Reshaper** لإعداد وتفريغ طبقات الصور بدقة أستوديو وتوليد الأختام العربية.
